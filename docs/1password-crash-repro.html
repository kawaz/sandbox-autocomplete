1Password Browser Extension Crash Reproduction

Bug Summary

When 1Password's OTP registration dialog (<com-1password-notification>) is visible and the user navigates to another page without closing the dialog first, the 1Password browser extension crashes. The extension popup becomes blank/white and all autofill functionality stops working for approximately 1 minute.

Environment

  • 1Password for Mac 8.12.8 (81208026)
  • Browser: Chrome (tested), likely affects all Chromium-based browsers
  • macOS

How to Reproduce

  1. Open this page. The QR code below contains a valid otpauth:// URI.
  2. 1Password should show an OTP registration dialog (notification bar).
  3. Without closing the 1Password dialog, click the link below to navigate away.
  4. The 1Password extension popup will become blank/white.
  5. All autofill and detection features will stop working until the tab is closed and ~1 minute passes.

Step 1: Trigger OTP Detection

The image below is a QR code containing an otpauth:// TOTP URI. 1Password should detect it and show a notification dialog.

If no dialog appears, make sure 1Password browser extension is installed and active.

Step 2: Navigate Without Closing

Once the 1Password OTP dialog is visible, click this link without closing the dialog first:

Navigate to example.com (triggers crash)

Step 3: Observe the Crash

After navigation, try opening the 1Password extension popup. It will be blank/white. Autofill will not work on any page until you close the tab and wait ~1 minute.

Root Cause (Hypothesis)

The <com-1password-notification> custom element persists in the DOM during page navigation. When the content script's context is torn down while this element still exists, the extension enters an inconsistent state.

Workaround (UserScript)

Removing the notification element before navigation prevents the crash:

Workaround UserScript (Gist)

const rmOP = () => document.querySelector('com-1password-notification')?.remove();
window.addEventListener('beforeunload', rmOP);
window.navigation?.addEventListener('navigate', rmOP);
